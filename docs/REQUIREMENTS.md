# Требования и чем они подтверждены

Этот файл — для проверяющего. Слева требование, справа: где оно живёт в коде, как
проверить самому и какой результат получили мы. Ничего из написанного здесь не взято
«по ощущениям» — каждая цифра либо измерена на сервере `10.103.10.86`, либо считается
автоматическим тестом.

Дата последнего прогона: **19.09.2026**, 238 тестов зелёные, `ruff` и `mypy` чисто.

## Задача №5 — автоматизация call-центра с узбекской речью

| # | Требование | Где сделано | Как проверить | Результат |
|---|---|---|---|---|
| 5.1 | Звонок на внутренний номер соединяет с помощником | `asterisk/extensions_custom.conf`, контекст `eduvoice-ai` | позвонить на 7000 | приветствие на узбекском, 8,8 с; меню нет намеренно — см. ниже |
| 5.2 | Распознавание узбекской речи | `eduvoice/voicelab.py::VoiceLabSpeechToText` | `make logs` + звонок | распознано дословно, включая `Akademik taʼtilda stipendiya toʻlanadimi?` |
| 5.3 | Синтез узбекской речи | `VoiceLabTextToSpeech`, кэш на диске | `make voice-prewarm ARGS=--dry-run` | 17 постоянных фраз озвучены разово; демонстрация не тратит кредитов на синтез |
| 5.4 | Ответ по существу вопроса | `eduvoice/brain.py`, `content/faq.yaml`, база знаний CRM | `uv run pytest tests/test_faq_accuracy.py` | **10 из 10** контрольных вопросов (порог плана — 8) |
| 5.5 | Перевод на живого оператора по просьбе | `brain.py` → `session.py::_act` → очередь `eduvoice-operators` | сказать «operator bilan gaplashmoqchiman» | перевод за 1,6–2,5 с, оператор снимает трубку |
| 5.6 | Перебивание: человек заговорил поверх **ответа** — помощник замолчал | `eduvoice/vad.py::BargeInDetector` | сказать что-нибудь во время ответа | замолкает за ~0,3-0,5 с; **приветствие перебить нельзя** — намеренно, см. ниже |
| 5.7 | Запись разговоров | `MixMonitor` в диалплане, плеер в CRM | открыть звонок в CRM | запись с метками по каждому вопросу, перемотка (HTTP 206) |
| 5.8 | Рабочее место сотрудника | `crm/` — обращения, граждане, аналитика, роли | `http://10.103.10.86:9095` | 34 маршрута, три роли, двуязычный интерфейс |
| 5.9 | Устойчивость: сбой не оставляет человека в тишине | `registry.py::DEFAULT_NEXT`, `Dial(AudioSocket/…,,g)` | остановить мост во время разговора | звонящий уходит в очередь операторов, оператор отвечает |

### Два решения, принятые на живых звонках 19.09

**Меню убрано.** Раньше 7000 вело в голосовое меню: «1 — помощник, 0 — оператор». На
живых звонках стало видно, что люди по привычке нажимают 0 и до помощника не доходят
вовсе. Теперь 7000 соединяет с помощником сразу; попросить человека можно голосом
(«operator bilan gaplashmoqchiman»), и помощник сам переводит, когда не справляется.

**Приветствие нельзя перебить.** Оно объясняет, что это за служба и как ей пользоваться,
и звонящий, который слышит её впервые, должен дослушать. В шумном зале приветствие
обрывалось шумом за полсекунды — человек не успевал понять, куда попал. Ответ и фразу
«одну минуту, проверяю» перебить можно. Включить перебивание приветствия обратно:
`INTERRUPTIBLE_GREETING=1` в `.env`.

## Задача №3 — ответы строго по нормативным документам

| # | Требование | Где сделано | Как проверить | Результат |
|---|---|---|---|---|
| 3.1 | Ответ опирается на действующий документ | `content/faq.yaml`, поле `source`; таблица `knowledge` | открыть любой звонок в CRM | у каждого ответа номер постановления и пункт |
| 3.2 | Модель не может выдумать норму | `brain.py`: правила поверх модели | `pytest tests/test_brain.py tests/test_lex.py` | выдуманный `faq_id` не озвучивается, пустой ответ не озвучивается; ответ модели «из головы» звучит, только если его подтверждает пункт закона — тогда читается пункт, с номером |
| 3.3 | Текст ответа меняется без программиста | база знаний CRM, `store/knowledge.py` | правка и «Опубликовать» | следующий звонящий слышит новую формулировку, без перезапуска |
| 3.4 | Черновик не попадает к гражданину | мост читает только `status='published'` | сохранить черновик и позвонить | звучит прежний опубликованный ответ |
| 3.5 | История правок сохраняется | `knowledge_versions` | вкладка «Версия» в карточке ответа | прежний текст и автор каждой правки |
| 3.6 | Вопрос вне FAQ — ответ всё равно по документу | `store/lex.py`, `brain.py::_from_law` | `make lex-ask Q="…"` | 9 актов, 2377 пунктов; ответ с номером пункта и ссылкой прямо на него |
| 3.7 | Нет пункта — нет ответа | тот же `_from_law` | спросить про погоду или футбол | перевод на оператора, а не придуманный ответ |

Использованные документы (сверены на lex.uz 18.09.2026):

- **59-сон** от 31.01.2020, пункты 6, 21, 22 — стипендия;
- **344-сон** от 03.06.2021, пункты 2, 3, 5, 7, 10 — академический отпуск;
- **578-сон** от 13.09.2025, приложение 3, пункты 15, 18, 19, 20 — перевод.

Устаревшее положение 393-сон от 20.06.2017 силы не имеет с 15.09.2025 — в ответах его нет.

## Качество кода

| Показатель | Значение |
|---|---|
| Автоматические тесты | 238, все зелёные |
| Линтер и проверка типов | `ruff` + `mypy`, без замечаний |
| Независимые аудиты | 4 круга, 10 независимых проверок, все находки закрыты тестами |
| Секреты в репозитории | нет — вся история коммитов просканирована |

Тесты не требуют ни телефона, ни ключей, ни сети: сквозной тест проигрывает настоящий
звонок через TCP-сокет ровно так, как это делает Asterisk
([tests/test_end_to_end.py](../tests/test_end_to_end.py)), а отдельный набор
([tests/test_session_failures.py](../tests/test_session_failures.py)) отвечает на один
вопрос — может ли человек остаться в тишине.

## Чего сознательно нет

Названо прямо, чтобы проверяющий не искал: HTTPS (доступ по внутренней сети под паролем),
срок хранения записей, двухфакторная аутентификация, разграничение доступа по отделам,
поиск по полному тексту нормативных актов (RAG). Обоснование каждого — в
[DATA.md](DATA.md) §6 и [AUDIT.md](AUDIT.md).

## Проверить самому за десять минут

Пошаговый сценарий с ожидаемым выводом каждой команды — [CHECKS.md](CHECKS.md).
Если коротко:

```bash
make check                         # 238 тестов, линтер, типы
make status                        # службы, порты, внутренние номера
make call-test                     # Asterisk сам звонит помощнику
make logs                          # видно: heard, decision, задержки
uv run pytest tests/test_faq_accuracy.py -v   # 10 из 10 контрольных вопросов
```

Затем открыть `http://10.103.10.86:9095`, войти супервайзером, открыть звонок, нажать
метку вопроса в записи, изменить ответ в базе знаний, опубликовать — и позвонить ещё раз.
